# Woolen Wonders Hub

Build a complete, beautiful, responsive website for my small business called Woolen Decorations, which sells handmade woolen decoration mats, rangoli mats, pooja mats, torans, door hangings, and custom-designed woolen products.

Create an elegant traditional Indian-inspired design with cream, maroon, dark green, and golden accents. Include a home page, latest products gallery, custom orders section, and contact details.

Display these features: Ready to Use, Washable, Price Depends on Size, and Custom Orders Available.

Most importantly, create a secure owner-only admin dashboard. The owner must be able to log in and upload product photos directly from a phone or computer, add product names and descriptions, publish, edit, replace images, and delete products without changing code or redeploying the site. New products should automatically appear first in the public gallery.

Use React, TypeScript, Tailwind CSS, and Supabase for authentication, database, and image storage. Enforce owner permissions using backend authorization and Supabase RLS. Public visitors can view published products but cannot manage them. No online payments or shopping cart are required.

Include a WhatsApp enquiry button, custom order form, clickable phone number, address, and Google Maps link.

Test the full workflow: owner login, upload image, publish product, and verify that it appears on the public website. Provide deployment and setup instructions.
